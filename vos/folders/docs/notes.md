# Нотатки

Корисна шпаргалка для роботи з системою.

## Гарячі клавіші

- `Ctrl+S` — зберегти файл
- `Ctrl+Shift+S` — зберегти як
- `Ctrl+O` — відкрити файл

## Поради

1. Зображення відкриваються у Переглядачі зображень.
2. ZIP-архіви відкриваються у Zipper.exe.
3. Текстові файли відкриваються у Блокноті.
