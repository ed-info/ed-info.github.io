        Довідка
        

          
Програма пишеться на Python і виконується рушієм Skulpt.
             Можливості робота дає модуль robot:

          
from robot import * — або import robot
             і тоді robot.forward(2).

          
Рух: forward(n), backward(n),
             left(), right(),
             north(n), south(n),
             east(n), west(n)

          
Фарбування: paintWhite(), paintBlack()
             вмикають режим малювання сліду, який триває до
             stopPainting()

          
Energon: pickUp()

          
Зір: frontIsObstacle(), frontIsClear(),
             frontIsEnergon(), frontIsWhite(),
             frontIsBlack() — так само для left… і
             right…

          
Стан: position(), direction(),
             EnergonLeft(), collected(),
             EnergonTotal()

          
Швидкість: setSpeed(v) — рівень 0–10
             (0 найповільніше, 10 найшвидше); getSpeed()
             повертає поточний рівень.

          
Скін: skin("grass") — перемикає оформлення
             карти; назви: grass, desert,
             mind, lego, default.

          
Збір Energon: під час pickUp() змінна
             collect збільшується на 1 (її ж показує
             collected()). Коли зібрано всі Energon — з'являється
             вікно з привітанням.

          
Зіткнення: при наїзді на перешкоду виникає
             CollisionError і програма зупиняється.
             Перехопити можна так:
             try: forward(10)
except robot.CollisionError: pass

          
Приклад:

          
from robot import *

paintWhite()
for _ in range(4):
    forward(2)
    right()
stopPainting()
