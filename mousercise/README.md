# Мишоловки — графічна версія

Окрема графічна версія навчальної гри «Мишоловки». **Оригінальна тека
`mousercise/` не змінювалася** — ця гра лежить у власній теці
`mousercise-game/` і працює незалежно від неї.

## Як запустити

Відкрийте `index.html` у браузері (подвійний клік) або подайте теку через
локальний вебсервер:

```bash
cd mousercise-game
python3 -m http.server 8080
# http://localhost:8080/
```

Зовнішніх залежностей немає: графіка сертифіката й миша лежать у файлах
`background.png`, `gold-ribbon.png`, `gold-stamp.png`, `sign.png`, `mouse.png`;
решта ілюстрацій — вбудовані SVG та CSS, звуки генеруються через Web Audio API.

## Прогрес і запуск із потрібної вправи

- Пройдені вправи та останній прогрес зберігаються у `localStorage` браузера.
  Наступного запуску гра одразу відкриває вправу **після останньої пройденої**.
- На вітальному екрані «Обрати вправу» — це два ряди кружків із номерами
  вправ. Пройдені вправи світліші (зелені), поточна — в жовтій рамці;
  натисніть будь-який кружок, щоб перейти до вправи. Лічильник
  «Пройдено N із 40» є і в панелі гри.
- Запуск із конкретної вправи через параметр URL `?level=` (номер вправи,
  як у грі, тобто як на екрані):

  ```
  index.html?level=1     → Вправа 1
  index.html?level=14    → Вправа 14
  index.html?level=26    → Вправа 26
  index.html?level=41    → Вправа 41 (остання)
  index.html?level=0     → показати вітальний екран
  ```

  Параметр `?level=` має пріоритет над збереженим прогресом. Під час гри
  адреса автоматично оновлюється, тож посилання можна скопіювати з рядка браузера.

## Що всередині

- **40 вправ** у тій самій послідовності, що й в оригіналі (m1–m41, без m25):
  кліки по цілях різного розміру, точність, пошук посилань і кнопок,
  подвійний клік, прокручування (вертикальне, горизонтальне, обидва),
  вікно сповіщень, лабіринт, прапорці, перемикачі та спадні меню.
- **Графіка**: мишка-маскот Мишо, сир-цілі, петарди, ілюстрації-емодзі,
  яскраві картки, анімації, конфеті.
- **Зручності**: рядок прогресу, кнопки «Підказка», «Повторити», «Звук»,
  автоматичне збереження прогресу, сертифікат із ім’ям та часом проходження
  (його можна роздрукувати).
